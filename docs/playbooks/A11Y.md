# Accessibility

A focused audit: can someone use the app with only a keyboard, with a
screen reader, with weaker eyesight or a zoomed window? Report only
(adding tests is allowed). Read `docs/audits/strategy/RULES.md` first.
Being asked to run this prompt is the owner asking you to run the app
(probes and one-off Playwright scripts per `TOOLKIT.md`).

Use Playwright only. Adding a checker such as axe-core is a new dependency
(licence notices, upkeep): propose it in the report rather than install it.

Argument: a page; default every page and overlay.

## You are the lead — target under 40 tool calls

1. **Baseline.** Read CLAUDE.md "UI conventions" once. Record commit and
   version; `npm run check`; `npm run build` once for the helpers'
   `--no-build` scripts.
2. **Missions (helpers, in parallel)**, each briefed with the rules quoted,
   the run folder, and "follow `docs/audits/strategy/RULES.md`; stop at 40
   tool calls". Results as text (what got focus, the accessible name, the
   ratio), not screenshots.

| Mission | Goal |
|---|---|
| **A. Keyboard** | On every page and overlay, Tab from the top through everything: each control reachable, in the order it appears, with a visible focus change (compare computed styles before and after focus); no trap. Enter/Space work them; arrow keys where a group expects them. Escape closes profiles, dialogs and menus and focus returns to what opened them; a dialog keeps focus inside while open. The desktop app's own window controls. |
| **B. Names and structure** | Every button and icon has a name (CLAUDE.md: `title` + `aria-label` on icon actions); every input is labelled; picked/on states are announced (`aria-pressed`/`aria-selected`/`aria-current`), not only shown green; headings in order; tables have header cells; graphs have their figures in text somewhere. Use `locator.ariaSnapshot()` or the accessibility tree, a page at a time, filtered. |
| **C. Seeing** | Text contrast at least 4.5:1 (3:1 for large text) from computed colours, including figures on comparative tints at their strongest and with the palette switch off; meaning never by colour alone (a tint always has its figure); at 200% zoom and a 1024 px window nothing is lost or overlaps (CLAUDE.md "Same layout at every screen size", "Whole words"); motion respects `prefers-reduced-motion`. |

3. **Verify and write.** Severity: a task that can't be done by keyboard
   or that a screen reader can't name is High; poor contrast on figures
   Medium; the rest by impact. New run folder
   `docs/audits/results/<YYYY-MM-DD>-a11y/`; `1-audit.md` in the Phase 1
   output format; add its row to `docs/audits/README.md` "Past runs";
   commit report, row and tests: "Accessibility <date>: report". The owner
   fixes findings with `/audit 2`.
